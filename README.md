# Telegram Bot huekrads_bot

Модульный Telegram-бот для групповых чатов с играми, случайными событиями, статистикой, триггерами и автоматическими реакциями.

## Функционал

### 🎭 Пидор дня

* Ежедневный автоматический выбор «Пидора дня» по расписанию
* Просмотр топа участников по результатам прошлых дней
* Принудительный запуск выбора администратором
* Хранение статистики в SQLite
* Поддержка дней рождения пользователей

### ⚔️ Гномья дуэль на ножах

Игровая дуэль между участниками чата.

* Вызов конкретного участника через `/duel`
* Выбор атакующей и защищаемой зоны
* Победа или поражение в дуэли
* Система очков
* Максимум 100 очков
* Ежедневное восстановление стартового количества очков
* Возможность потерять хуй в результате поражения
* Если хуй украден — дальнейшие дуэли в этот день недоступны
* Статистика побед и поражений
* Учёт количества краж
* Топ дуэлянтов чата
* Удаление игрока из дуэльной базы администратором

### 👹 Битвы с боссами

Групповая боевая механика.

* Регистрация участников на битву
* Несколько участников одновременно сражаются с боссом
* Каждый игрок индивидуально выбирает зону атаки
* Каждый игрок индивидуально выбирает зону защиты
* Выбор атаки и защиты происходит заново в каждом раунде
* Босс в каждом раунде выбирает собственную зону атаки и защиты
* Ограниченное время на каждый ход
* Игрок может погибнуть в результате пропущенной атаки босса
* Урон боссу засчитывается за успешные атаки игроков
* Победа группы после нанесения необходимого количества попаданий
* Поражение при гибели всех участников
* Статистика побед над боссами
* Ежедневная автоматическая возможность появления босса

### 🍆 Гиперборейский хуй

Независимое случайное событие, не связанное с дуэлями или боссами.

* С определённой вероятностью в чате появляется кнопка **«🍆 ОБНАРУЖЕН ГИПЕРБОРЕЙСКИЙ ХУЙ»**
* Событие может появиться в любой момент
* Участники соревнуются, кто первым нажмёт кнопку
* Победитель возвращает себе хуй, если он был украден ранее
* Если у победителя хуй уже был:
  * его очки обнуляются;
  * он теряет хуй;
  * появляется сообщение: **«От передозировки хуев гнома разорвало на хуйные молекулы.»**
* Вероятность события не накапливается и не сбрасывается каждый день
* Одновременно в одном чате может существовать только одно такое событие

### 🌤 Погода

Инлайн-поиск погоды непосредственно из Telegram.

Использование:

`@имя_бота Москва`

Отдельной команды `/weather` нет.

### 🗣 Текстовые триггеры

* Реакции бота на определённые сообщения
* Поддержка пользовательских сценариев и ответов
* Автоматические реакции на сообщения в групповых чатах

### 💬 Отложенные ответы «Пизда»

Механика `past_pizda`.

* Бот собирает сообщения с «да» в специальный пул
* Позже случайным образом выбирает старые сообщения
* Через несколько дней бот может ответить на них «Пизда»
* Джоба работает автоматически
* Время отправки — в заданном дневном диапазоне
* Пул сообщений хранится в таблице `pizda_candidates`
* Стартовый пул можно загрузить из seed-файла или полного экспорта Telegram

### 🔧 Администрирование

Администраторам доступны:

| Команда | Назначение |
|---|---|
| `/top` | Топ-10 «Пидоров дня» |
| `/force_pidor` | Принудительно запустить выбор Пидора дня |
| `/setbday` | Установить день рождения пользователя |
| `/duel_delete` | Удалить игрока из дуэльной базы |
| `/toggle_forward` | Включить/выключить реакции на пересланные сообщения |
| `/toggle_autodelete` | Включить/выключить автоудаление команд |

### 📊 Команды пользователей

| Команда | Назначение |
|---|---|
| `/start` | Запустить бота |
| `/top` | Топ-10 «Пидоров дня» |
| `/duel` | Вызвать игрока на дуэль |
| `/duel_stats` | Статистика дуэлей |
| `/duel_top` | Топ-10 дуэлянтов |
| `/boss` | Запустить/посмотреть битву с боссом |
| `/boss_reg` | Зарегистрироваться на битву с боссом |

## 🗄 Хранение данных

Бот использует **SQLite**.

В базе хранятся:

* пользователи и статистика «Пидора дня»;
* дни рождения;
* настройки чатов;
* игроки дуэлей;
* статистика дуэлей;
* количество побед над боссами;
* пул сообщений для `past_pizda`;
* служебные данные бота.

При запуске через Docker база подключается как volume:

`-v $(pwd)/bot_database.db:/app/bot_database.db`

Это позволяет сохранять данные при пересоздании контейнера.

## Отложенные «Пизда» (`past_pizda`)

Пул сообщений лежит в таблице `pizda_candidates`. Живые «да» бот дописывает сам. Стартовый пул заливается скриптом.

### Залить пул на проде из seed

После выполнения:

`python handlers/past_pizda.py --export-seed`

файл `data/pizda_candidates_seed.json` должен находиться рядом с кодом.

Запуск:

`python handlers/past_pizda.py`

В Docker:

```bash
docker cp data/pizda_candidates_seed.json da-pizda-bot:/app/data/
docker exec -w /app da-pizda-bot python handlers/past_pizda.py
